# Scripts

This directory contains utility scripts and smoke test suites for the GramUdaan application.

## Contents

- `build-pin-index.mjs`: Generates and compresses nationwide PIN code and location datasets used for offline and quick-lookup search.
- `capital-breakdown-smoke.ts`: Smoke tests for capital allocation, investment tier calculation, and cost breakdown models.
- `financial-smoke.ts`: Smoke tests for financial feasibility, affordability calculations, and cash flow projections.
- `gramudaan-smoke.ts`: End-to-end smoke tests for the primary feasibility assessment and scoring pipeline.
- `hyperlocal-smoke.ts`: Smoke tests for local market intelligence, population reach, and competitor density metrics.
- `plan-smoke.ts`: Smoke tests verifying the business planning and dynamic what-if simulation models.
